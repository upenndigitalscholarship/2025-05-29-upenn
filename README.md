# CURF Carpentries 2025

Are you interested in learning more about research computing or programming? Penn Libraries and the Graduate Student Center would like to offer intensive Data Carpentries workshops for Penn graduate and professional students May 29th & 30th, 2025. You can visit the Carpentries/Data Carpentries website to learn more (https://datacarpentry.org/socialsci-workshop/). Space is limited and we anticipate high demand! If you have any questions, please reach out to libraryrdds@pobox.upenn.edu.
